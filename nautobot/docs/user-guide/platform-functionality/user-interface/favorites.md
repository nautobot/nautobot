# Favorites

+++ 3.0.0

+++ 3.3.0 "Added support for favoriting any page, no longer restricting the favorite items to those from the navigation menu"

Favorites give you quick access to your saved pages. They are listed in the Favorites flyout of the navigation menu, and they are private to your user account.

## Adding a Favorite

Any page can be favorited with the star next to its title. The star opens a short form where you can edit the name the favorite item will be listed under, and the link it will point to.

Items in the navigation menu can also be favorited directly, using the star that appears beside an item when you hover over it. Note that pages favorited directly from the navigation menu include a subtitle, while those added from the form are identified only by their name.

## Working with Favorites

Open the Favorites flyout from the navigation menu to see all the favorite pages. Entries can be reordered by drag and drop, and removed by clicking the active star for that page.

A favorite stores the address of the page exactly as it was when you saved it, together with the name that was given to it. Neither is updated afterward, so any modification requires removing the old and adding a new one.

!!! tip
    Filters, tabs, initial form values, etc., are expressed in query parameters of a page URL. This means a filtered list view can be saved as a favorite, and so can a specific object detail view tab, or a form with pre-filled values. This is a convenient way to keep shortcuts to the features you use most, which would otherwise take several clicks to reach.
