Due to updating `social-auth-core` and `social-auth-app-django`, deployments that override the `SOCIAL_AUTH_PIPELINE` setting may need to update their configuration to add an entry for`"social_core.pipeline.social_auth.social_names"`. If this is not added, some SSO backends may no longer automatically populate the `first_name` and `last_name` fields when creating new User records in Nautobot.
