Added long-term retention models for change and job history. `ArchivedObjectChange`, `ArchivedJobResult`, `ArchivedJobLogEntry` and `ArchivedJobConsoleEntry` mirror the existing `ObjectChange`, `JobResult`, `JobLogEntry` and `JobConsoleEntry` models, with foreign keys to other models stored as plain identifier columns.
Added a database index on `JobConsoleEntry` for retrieving a job result's console output in timestamp order.
Added the `is_custom_field_model` flag to `CustomFieldModel`, which a model can set to `False` to opt out of custom field support.
